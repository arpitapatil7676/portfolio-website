# Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my **projects, technical skills, professional experience, certifications, and achievements**.

The portfolio highlights my work in **Python, Generative AI, AI-assisted technologies, and frontend development**, with an interactive and visually focused design.

## ✨ Features

* Responsive portfolio design
* Dark / Light mode
* Framer Motion animations
* Interactive typewriter effect
* Animated statistics
* Project showcase
* Skills and technology section
* Education and certifications
* Professional experience section
* Resume download
* Contact section
* Custom cursor interactions
* Mobile-friendly interface

## 🛠️ Tech Stack

* **React**
* **TypeScript**
* **Vite**
* **JavaScript**
* **HTML5**
* **CSS3**
* **Tailwind CSS**
* **Framer Motion**
  

## 📂 Portfolio Sections

* **Home** – Introduction and professional profile
* **About** – Background and areas of interest
* **Skills** – Programming, frontend, Generative AI, tools, and soft skills
* **Experience** – Internship and professional experience
* **Projects** – Selected AI, software, and web development projects
* **Certifications** – Professional certifications
* **Education** – Academic background
* **Contact** – Contact and professional links
